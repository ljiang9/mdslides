# mdslides 演示

**Markdown** 进，单文件 *HTML* 幻灯片出。

- 零外部请求：无 CDN、无字体、无构建
- 幻灯片以 `---` 分隔
- 按 `n` 查看讲稿

<!-- note: 开场先讲痛点：做个分享还要搭构建工具太重了。 -->

---

## 支持的 Markdown 子集

- `#` / `##` / `###` 标题
- `-` 无序列表、`1.` 有序列表
- **粗体**、*斜体*、`行内代码`
- `>` 引用块

> 比如这样一句引用

<!-- note: 强调这里只支持子集，表格不支持，别问。 -->
